# v0.5.0

## English

- **Choose before switching.** `omime choose` opens a keyboard and pointer picker.
  Browse the enabled input methods, confirm with Enter or a click, or cancel with Escape.
- **Remember Chinese/Latin mode per app.** Enable `apps.remember` and
  `apps.remember_mode` to restore Rime's confirmed mode before the next key. The tray,
  settings and `omime status --json` show the current mode. Engine protocol 1.2 makes
  this optional capability available to other engines.
- **More reliable input and shutdown.** Forwarded keys retain modifiers, slow or
  disconnected engines recover cleanly, and Rime can save learned phrases on exit.
  Queue and connection limits keep stalled clients from accumulating work indefinitely.
- **Stronger privacy and desktop integration.** Sensitive Fcitx fields discard cached
  surrounding text, engine error descriptions require debug logging, and configuration
  errors and notification-server restarts no longer disrupt the control interface.
  Setup checks desktop support before taking over another input framework.

Echo and Sparkle remain included but must be enabled explicitly in settings or with
`omime enable echo` / `omime enable sparkle`. Source builds require Rust 1.92 or newer.
Supported desktops remain Hyprland and sway; KDE Plasma and GNOME support is planned.

Prebuilt x86_64 and ARM64 Linux platform/Rime archives, the Nix release flake and
checksums are attached. To update a Nix flake input, run `nix flake update oh-my-ime`
and rebuild your configuration. See the [release guide](https://github.com/Ign1x/oh-my-ime/blob/v0.5.0/docs/releases.md)
and [full changelog](https://github.com/Ign1x/oh-my-ime/blob/v0.5.0/CHANGELOG.md).

## 简体中文

- **确认后再切换。** `omime choose` 打开支持键盘和鼠标的选择器；浏览已启用的输入法，
  按 Enter 或点击确认，按 Escape 取消。
- **按应用记住中英文模式。** 同时开启 `apps.remember` 和 `apps.remember_mode`，
  就能在下一个按键之前恢复 Rime 已确认的模式。托盘、设置和 `omime status --json`
  显示当前模式；引擎协议 1.2 也向其他引擎提供这项可选能力。
- **输入与退出更可靠。** 转发按键保留修饰键，引擎迟缓或断连后能够恢复，Rime 退出时有机会
  保存已学习的词句。队列和连接上限避免无响应的客户端无限积压任务。
- **改善隐私和桌面集成。** Fcitx 敏感字段清除周边文本缓存，引擎错误详情仅在调试日志中
  出现，配置错误和通知服务重启不再影响控制接口。接管其他输入框架前先检查桌面支持。

Echo 和 Sparkle 仍随安装提供，需要在设置中或通过 `omime enable echo` /
`omime enable sparkle` 显式启用。源码构建要求 Rust 1.92 或更新版本。
继续支持 Hyprland 和 sway；KDE Plasma、GNOME 支持仍在计划中。

附件包含 x86_64、ARM64 Linux 的平台与 Rime 预编译包、Nix 发布 flake 和校验和。
Nix flake 用户可运行 `nix flake update oh-my-ime` 后重新构建配置。
详见[发布指南](https://github.com/Ign1x/oh-my-ime/blob/v0.5.0/docs/zh-CN/releases.md)和
[完整更新日志](https://github.com/Ign1x/oh-my-ime/blob/v0.5.0/CHANGELOG.md)。
